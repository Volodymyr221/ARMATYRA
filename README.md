# КомпозитПром — лендинг композитної арматури

Односторінковий лендинг для продажу композитної (склопластикової) арматури.
Чистий **HTML5 + CSS3 + Vanilla JS**, без бібліотек і фреймворків. Mobile-first,
адаптив під 320 / 375 / 390 / 430 / 768 / 1024 / 1440 px.

## Структура файлів

| Файл | Призначення |
|------|-------------|
| `index.html` | Розмітка сторінки: header, hero, переваги, каталог, перемикач діаметра, прайс, порівняння, кроки, форма, футер, мобільна CTA-панель. Містить SEO-теги, Open Graph і schema.org. |
| `styles.css` | Уся стилізація. CSS-змінні (кольори/радіуси), mobile-first, медіазапити для планшета/десктопа, анімації наведення, `prefers-reduced-motion`. |
| `script.js` | Інтерактив: плавний скрол, перемикач діаметра з динамічним оновленням характеристик і ціни, маска та валідація українського телефону, надсилання заявки у Telegram. |
| `config.js` | Винесені налаштування: телефон, Telegram `BOT_TOKEN` і `CHAT_ID`. |
| `assets/favicon.svg` | Фавікон (логотип-«мішень»). |
| `assets/og-image.svg` | Зображення для соцмереж (Open Graph / Twitter). |
| `README.md` | Цей файл. |

## Запуск

Статичний сайт — відкрийте `index.html` або задеплойте теку на будь-який
статичний хостинг (Netlify, Vercel, GitHub Pages, звичайний nginx).

Локально:
```bash
python3 -m http.server 8080
# відкрити http://localhost:8080
```

## Налаштування під клієнта

1. **Телефон** — у `config.js` (`phone`, `phoneDisplay`). Він підставляється у всі
   кнопки `tel:`. За потреби оновіть номери також у `index.html` (footer / schema.org).
2. **Ціни** — у `index.html` (таблиця прайсу, картки каталогу) та в `script.js`
   (об'єкт `DIA` — характеристики й ціна по діаметрах).
3. **Telegram** — див. нижче.

## Telegram-інтеграція

У `config.js`:
```js
telegram: {
  enabled: true,
  BOT_TOKEN: "123456:ABC...",   // від @BotFather
  CHAT_ID: "123456789",          // від @userinfobot
}
```

Заявка з форми надсилається повідомленням у Telegram (ім'я, телефон, товар,
діаметр, кількість, коментар). Якщо токен не заповнено — форма все одно показує
успіх, а в консолі буде попередження (зручно для верстки без бекенду).

> ⚠️ **Безпека.** `config.js` виконується в браузері, тож `BOT_TOKEN` буде видно
> у вихідному коді. Для MVP/тесту це прийнятно. Для продакшену винесіть надсилання
> на сервер (Netlify Function або Supabase Edge Function), а токен зберігайте в
> змінних оточення. Тоді форма звертається до вашого ендпоінту, а не напряму до
> Telegram API.

## Перевірений UX-чекліст

- ✅ Усі кнопки/посилання робочі, `tel:` працює на мобільному.
- ✅ Плавний скрол з урахуванням висоти sticky-хедера.
- ✅ Перемикач діаметра оновлює характеристики, ціну й синхронізується з формою.
- ✅ Валідація форми + український формат телефону з маскою.
- ✅ Немає горизонтального скролу (`overflow-x: hidden`, адаптивні сітки).
- ✅ Фіксована CTA-панель на мобільних, прихована на десктопі.
- ✅ SEO: title, description, OG, favicon, schema.org (LocalBusiness, ціни).
- ✅ Швидкодія: без зовнішніх бібліотек, SVG-іконки, `defer` для JS, шрифти з preconnect.
